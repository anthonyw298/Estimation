# Dev Server

Start the Next.js development server with Turbopack.

## Steps

1. Ensure dependencies are installed:
   ```bash
   cd web && npm install
   ```

2. Start the dev server:
   ```bash
   cd web && npm run dev
   ```

The app will be available at http://localhost:3000
